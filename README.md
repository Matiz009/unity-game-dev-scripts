# Unity Game Dev Scripts

Unity C# scripts from my game development coursework and projects.

## What's inside

| Path | Contents |
|---|---|
| `alligator/` | Player movement, bullets, enemies, countdown, game over |
| `assign 1/` | Bus and traffic scripts, camera |
| `dino/`, `Heli/`, `CR/`, `solar/`, `puzzle/`, `fps/`, `multi player game/` | Scripts for individual game projects |
| Root `.cs` files | Shared mechanics: player and enemy movement, bullets, coin/cherry/snowball spawners, seasonal level movement, audio, score, UI manager |

## Usage

Copy a script into your Unity project's `Assets/` folder and attach it to a GameObject.
